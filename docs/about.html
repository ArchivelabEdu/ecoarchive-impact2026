소개

이 사이트에 대하여

환경아카이브 풀숲 데이터 랩은 재단법인 숲과나눔이 운영하는 환경아카이브 풀숲(ecoarchive.org)의 Omeka 데이터베이스 전수를 분석해, 6년간 무엇이 얼마나 쌓였는지를 컬렉션·시간·주제·지역·키워드의 관점에서 보여주는 사이트입니다.

「환경아카이브 풀숲 통합 임팩트 측정 보고서」(2026)의 접속통계 분석이 "누가 얼마나 봤는가"를 다룬다면, 이 사이트는 그 대칭으로 "무엇이 얼마나 쌓였는가"를 다룹니다.

만든 사람

  • 재단법인 숲과나눔 (환경아카이브 풀숲 운영)
  • 아카이브랩 (분석·사이트 구축)

데이터 기준

  • Omeka REST API 전수 111,106건, 2026년 9월 10일 수집
  • 매년 재산출 예정
